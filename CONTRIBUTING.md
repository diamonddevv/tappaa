# contributing to tappaa
thank you for your interest in contributing! it is greatly apprciated,
however here are some guidelines on contributions.

### bug reports
when reporting a bug, please include what mods you are using, as
well as a crash log (if appropriate) - upload crash logs to [mclo.gs](https://mclo.gs/) and provide the link (this will remove
any potentially sensitive information from the log, such as IPs)


### bug fixes
if you fix any bugs from the issues section, please reference them in the
pull request.

### ai usage
please dont.

### licensing
by contributing code, you agree that your code may be added to the project under 
the same license as the rest of the project.
